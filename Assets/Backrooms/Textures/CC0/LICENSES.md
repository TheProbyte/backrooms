# CC0 textures

All textures in this folder are CC0 (public domain) from ambientCG (https://ambientcg.com), 2K JPG sets.
`*_Mask.png` files are derived: R = 0 (metallic), G = ambient occlusion, A = 1 - roughness (smoothness).

| File prefix | Source asset |
| --- | --- |
| Carpet_ | Carpet016 |
| CeilingTile_ | OfficeCeiling001 |
| Plaster_ | PaintedPlaster017 |
| WallpaperPaper_ | Wallpaper001A (only its normal and roughness are used, under the procedural striped pattern) |
