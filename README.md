# Backrooms (working title)

Realistic camcorder-style Backrooms exploration game. Unity 6 (6000.4.5f1), URP.

![Spawn view](Docs/screenshots/spawn_view.png)

## Milestone 1: one office room + camcorder player

Open `Assets/Backrooms/Scenes/OfficeRoom_Prototype.unity` and press Play.

**Controls**

| Input | Action |
| --- | --- |
| W A S D | Walk |
| Hold Left Shift | Run (forward) |
| Mouse | Look |
| Esc | Release cursor |
| Left click | Re-capture cursor |

**Settings** (Inspector)

- `Player > CamcorderPlayerController`: mouse sensitivity, invert Y, walk/run speed, acceleration.
- `Player/CameraPivot/Camcorder > HandheldCameraShake`: master shake intensity plus idle/walk/run layers.
- `Camcorder > CamcorderAutoExposure`: target brightness, EV limits, adaptation speeds.
- `Camcorder_PostVolume` (`Assets/Backrooms/Settings/Camcorder_PostProfile.asset`): grain, vignette, lens, grading.

## How the room is made

The whole scene is generated by **Backrooms > Build Office Room Scene** (`Assets/Backrooms/Scripts/Editor/OfficeRoomBuilder.cs`),
which also regenerates the procedural textures and bakes bounce lighting. Re-run it after changing layout constants.

- Interior 7.2 x 6.0 m, 2.7 m ceiling, 0.6 m (2 ft) tile grid. Origin at floor centre (`RoomModule`).
- Walls are 1.2 m segments so a segment can later be swapped for a doorway when rooms are generated and connected.
- Six 1.2 x 0.6 m troffers; three work (realtime soft-shadowed spots, mixed/baked indirect), three are dead.
- Textures are procedural and seeded (`BackroomsTextureGenerator`), so there are no third-party assets to license.
- Fluorescent hum and room tone are synthesised at runtime (`ProceduralAmbience`), no audio files.
